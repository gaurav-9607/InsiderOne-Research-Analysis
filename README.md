# InsiderOne-Research-Analysis
Excel based job board application analysis covering data cleaning ,hiring trends visualization and buisness insight

Project Overview
An Excel-based analysis of job-board applications to understand hiring outcomes, application sources, application completion rates, and employer response times.
Dataset
Source: Job-board applications CSV (provided dataset)
Original records: 1,206 applications
Final records: 1,200 unique applications
Period: July–September 2026
Dataset: Synthetic data
Data Cleaning
Data cleaning was performed using Microsoft Excel.
Identified and removed 6 duplicate records using Excel's Remove Duplicates feature.
Retained 1,200 unique records.
No missing values or inconsistent values were corrected during this cleaning step.
Created a separate Cleaning Log sheet to document the method and results.
Analysis Performed
The workbook includes the following sheets:
Job-board-applications: Application dataset.
Cleaning Log: Data cleaning method and verification results.
Chart: Visualization of hires per 100 applications.
Manager Note: Key findings and business recommendations.
Key Findings
1. Application Sources
Referrals generated approximately 10.57 hires per 100 applications overall. However, the best-performing source varied by role category.
2. Application Completion
Applicants completing all four steps had a 48.39% shortlisting rate, compared with 9.28% for applicants completing fewer than four steps.
3. Paid vs. Unpaid Roles
Paid roles received replies faster, averaging 3.22 days compared with 7.63 days for unpaid roles. Approximately 13% of paid applications and 30% of unpaid applications never received a reply.
Business Recommendations
Encourage applicants to complete all four application steps.
Investigate ways to improve response times for unpaid roles.
Continue using referrals while evaluating the best source for each role category.
Data Limitations
This is a synthetic dataset and may not represent real hiring behaviour. Missing reply dates and other data-quality issues should be considered before making major business decisions.
